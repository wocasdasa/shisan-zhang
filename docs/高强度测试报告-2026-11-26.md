# 《广西十三张·独食》高强度测试与修复报告

日期：2026-11-26  
范围：引擎规则 / 联机服务端协议与房间生命周期 / 小游戏客户端异常消息与联机交互

## 1. 结论

本轮以「规则模糊测试 + 服务端协议/生命周期测试 + 客户端无头交互 + 像素级视觉回归」四条线并行推进，发现并修复了 4 类真实产品缺陷：

1. **联机进贡客户端与服务端协议完全错位**：客户端发 `drawPick` / `pullPick` / `retOne`，服务端只认 `draw` / `return`，真人抽牌、还贡请求被静默丢弃。
2. **独食 12 张还贡被 8 张消息上限误拒**，且还贡缺少身份牌/持牌/张数校验。
3. **房间生命周期缺口**：总结页房主掉线无人接管、总结页无法再来一场、点「回到开始界面」只改本地 phase 留下幽灵座位、换房失败会先丢掉原座位、跨房 rejoin 会留下幽灵座位、同一 key 双端登录会互相重连踢人。
4. **进贡 UI 与服务端状态不一致**：抽牌金框在非本人回合也亮、已抽满座位仍可点，还贡阶段联机拿不到 `ret` 导致一张牌都选不上。

修复后所有自动化回归全绿，视觉矩阵竖屏/横屏各 24/24 一致。另有 1 项测试脚本自身缺陷（`IDLE_CLOSE_MS` 被硬编码覆盖）已修复，不是产品问题。

## 2. 产品代码修复清单

### 2.1 进贡协议与还贡（P0）

- `minigame/js/app.js`
  - 联机 `drawFromSeat` 改发 `{ t:'draw', seatRel }`，并校验 `T.myTurn`、独食抽牌方向每败方配额。
  - 联机 `pullOne` 改发 `draw`。
  - 联机 `confirmReturn` 改发批次 `{ t:'return', cards }`，要求 `cards.length === T.need`。
  - `applyView` 在 `stage='return'` 时补 `ret:{total:T.need, idx:0, curFrom:-1}`，修复 `retRemaining()` 恒 0 导致无法勾牌。
  - `toggleReturnSelect` 拦截身份牌（♠3/♠A 不能还贡）。
- `server/index.js`
  - `cardList(v,maxLen)`：`play` 仍 8 张，`return` 允许 13 张，修复独食 12 张还贡被拒。
  - `return` 增加张数 = `need`、不得含身份牌、每张必须在自己手里的校验；非法请求只回 `err`，不改手牌。
  - `view.tribute` 新增 `drawNeed`、`picks`、`draws[].to` 相对座位；`pulledFrom` 标记 `pulledFromRel:true`。
  - 身份牌重复随机命中只公示/记录一次，避免日志与座位徽标重复。

### 2.2 房间生命周期（P0/P1）

- `server/ws.js` 新增 `socket.on('end')` → `socket.end()+finish()`：客户端只发 FIN 的半关闭连接 2.5s 内回收。
- `server/index.js`
  - 5s 扫描在把掉线真人转 AI 后先 `ensureHost(room)` 再广播；总结页 `summary` 也纳入扫描，修复总结页房主掉线无人能点「再来一场」。
  - `next` 支持 `summary` 阶段：房主重开同房新一场（分数/局数归零）。
  - `joinRoom` 先校验目标房（已开局/已满）再退旧房，避免换房失败丢原座位。
  - `rejoinRoom`：同连接不能占同房两个座位；跨房 rejoin 先正常退旧房，避免旧房留下幽灵真人。
  - 重连接管旧连接前发送 `superseded`，避免旧端自动重连形成互踢循环。
  - 房主掉线转 AI 后房主转交在线真人（此前已修，本轮回归确认）。
- `minigame/js/app.js`
  - 处理 `superseded`：清 `rejoin` 凭据、回联机大厅并提示，不再自动重连。
  - 联机总结页「再来一场」由房主发 `{t:'next'}`；非房主只提示等待。
  - 总结页「回到开始界面」联机时真正 `backToSolo()` 退房，而不是只把本地 `phase` 改成 `menu`。
  - `backToSolo` 清理 `summary/lastResult/tribute/deal/selected`，避免总结遮罩叠在开始界面。
  - 主动退房关闭连接时不再弹「连接断开」盖住操作提示。

### 2.3 进贡 UI 与服务端状态对齐（P1）

- `minigame/js/views/table.js`
  - 联机抽牌金框/热区要求 `S.tribute.myTurn`；独食抽牌方向已抽满的座位不再画金框、不再产生 `drawSeat` 热区。
  - 联机不再用服务端不下发的 `TR.turnW` 判断抽牌者，消除「非我回合也显示点我抽牌」。
- `minigame/js/views/panels.js` 抽牌进度显示「还差 X 张」；联机还贡显示「选 N 张 / 等待对方还贡」，`need=0` 隐藏还贡按钮。

### 2.4 其它

- `engine/table.js` 与 `minigame/js/engine/table.js`：删除重复块，显式 `firstPlayer` 优先并 `firstPlayPending=false`，否则按 ♦4 持有者；`sync-engine --check` 12 个文件一致。
- `server/index.js` 房间配置下发 `tributeTier/turnSeconds/teamHint/testTribute`；`testTribute` 第 1 局直接演练进贡；`teamHint` 真正下发队友标记（独食局不泄露）。
- `minigame/js/app.js` 单机/联机队友徽标改用 `S.mode` 分支，单机不再因 `S.seats` 占位数组而永不显示。
- `tools/netbot.js` 增加抽牌 600ms 去重与已抽满座位过滤；新增 `REMATCH=1` 全流程再来一场验证。
