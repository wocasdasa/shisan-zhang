# 十三张·独食 — 小游戏界面重设计（布局 + 主题 + 特效）

日期：2026-11-20 ｜ 状态：待批准 ｜ 范围：`minigame/js/views.js`、`minigame/js/app.js`、`minigame/js/audio.js`

## 1. 意图与为什么

当前竖屏牌桌中央大片留白、座位牌小且分数脱节、手牌拥挤、顶部按钮碎小；♠3/♠A 是这游戏的核心记忆点（组队/独食身份牌），但打出时只在座位旁出现一个小标记，毫无仪式感。本次重做布局与视觉主题，升级牌型特效，并为两张身份牌做专属特效，让"打出身份牌"和"独食现身"成为全桌都看得见的高光时刻。

## 2. 目标

- **G1 新主题**：深绿牌桌 → 暗夜墨蓝牌桌 + 鎏金 + 朱红强调，整体观感"换肤级"变化。
- **G2 布局重排**：中央出牌区成为视觉中心；座位牌加大并整合分数；手牌宽松、选中反馈明显；顶部按钮统一为一排胶囊。
- **G3 牌型特效升级**：每种牌型触发居中大字横幅；四条加全屏震动+冲击波；同花顺加彩虹连环+满屏流光；同花按实际花色着色粒子。
- **G4 身份牌专属特效（新增）**：
  - 任何人打出 ♠3 或 ♠A：黑金光柱 + 黑桃花色粒子炸开 + 身份徽标从桌中央飞入该玩家座位；
  - 同一玩家两张都打出：桌面压暗 → ♠3♠A 双牌中央合并 →「独食」朱红大字砸下 + 震屏 + 黑红粒子爆发，该玩家座位牌边框转朱红常驻。

## 3. 非目标

- 不改规则引擎 `engine/` 与 `minigame/js/engine/`；不改联机协议与服务端 `server/`。
- 不改进贡流程逻辑（仅适配新配色）。
- 不引入任何图片/音频素材：全部 Canvas 程序化绘制 + WebAudio 合成。
- 不做断线重连、上架材料（README 已列为未做项）。

## 4. 反目标（做好了也算失败）

- 特效遮挡操作：特效层只是绘制、不新增热区，且任何特效 1.2 秒内淡出到不干扰读牌的程度。
- 低端机掉帧：同屏粒子总数 ≤ 60，阴影 blur 仅在激活座位等少量元素上使用；竖屏 750 宽设计稿在 preview.html 保持流畅。
- 热区与视觉错位：`draw()` 返回的 hits 必须与新布局逐一对应（`tools/cdp-hitcheck.js` 可验证）。

## 5. 约束

- 纯 Canvas，无 DOM；设计宽 750，由 `platform.js` 缩放适配。
- `game.json` 为横屏（landscape），浏览器 preview 竖屏也要可用：`layout()` 的横/竖两个分支都要按新设计同步重做。
- 特效沿用 `S.fx.*` 时间戳 + `markDirty()` 重绘模式；`app.js` 的脏检查需纳入新增时间戳字段。
- 联机模式下身份揭示状态由服务端 `state` 同步，特效触发必须基于客户端本地状态变化（对比前后 revealed 标记），不依赖单机独有路径。
- 验证路径：`node tools/build-mini-preview.js` 重新生成 `preview.html`；`?demo=fx`、`?fx=<p>&kind=<kind>` 调试入口保持可用并扩展到新特效。

## 6. 方案取舍（Approaches）

| 方案 | 内容 | 取舍 | 结论 |
|---|---|---|---|
| A | 保留深绿+鎏金，只做精 | 改动最小，但与"重做"目标不符 | 排除（用户已选 B） |
| **B** | **换主题：暗夜墨蓝 + 鎏金 + 朱红** | 鎏金延续现有粒子色系，特效色板改动小；朱红天然服务独食/警告语义 | **选定** |
| C | 暗夜霓虹（青紫高饱和） | 与现有金色粒子体系冲突，全部特效需重调，返工大 | 排除 |

主题色定为 B 是本设计的决策（用户只指定"换主题"，具体色向由我方定）：墨蓝显牌、鎏金延续资产、朱红专用于独食/倒计时警告/危险确认。

## 7. 设计细节

### 7.1 配色（替换 views.js 顶部 C 表）

| 角色 | 现值 | 新值 |
|---|---|---|
| 背景底 | `#081d14` | `#0a121f` |
| 背景渐亮 | `#143f2c` | `#16273f` |
| 牌桌毡 | `#14432f` | `#1a2f4d`（径向微光） |
| 金（主） | `#c9a961` | `#d8b36a`（略提亮） |
| 面板 | `#0e2a1f` | `#0f1b2e` |
| 按钮 | `#1b3a2b` | `#1c2f4a` |
| 文字/弱文字 | `#efeadb` / `#9db1a4` | `#f2ead8` / `#93a3ba` |

### 7.2 布局（竖屏 750 宽为基准，横屏等比映射）

- **页头**：左侧标题「十三张·独食」+ 副标（单机/联机·房间号）；右侧一排胶囊按钮：场次 / 进贡档 / 对手强度 / 音效 / 重开，高 44、圆角 22、间距 8，文字 15。
- **座位牌**：宽 176 × 高 64；左圆徽（直径 40，含座名首字），右侧上行名字、下行「N 张 · +分」——分数整合进牌内，不再挂最右端。轮到出牌的座位：金边 + 外发光脉冲（沿用现有 active 语义）。
- **牌桌中央**：出牌区上移至视觉中心（约 H×0.40），每手牌组最大展示宽度加大约 30%，牌型标签（如「同花顺」）放在牌组正上方；最新一手金框、旧牌压暗（沿用）。
- **手牌**：牌宽约 64、高约 90、横向重叠步进约 52，13 张居中；选中牌上移 22px + 金描边；手牌区与桌面之间留「压过桌面或过牌」提示行。
- **操作条**：「提示 / 过牌 / 出牌」一行居中，倒计时从独立数字改为嵌在「出牌」按钮左侧的环形进度（复用现有 clockChip 样式）。
- **南家座位牌**：移至手牌区左上方，与手牌形成一组，不再孤悬桌面中央。

### 7.3 牌型特效（在现有 kindFx 基础上升级）

- **新增居中横幅**：任何非单张牌型触发时，屏幕中央偏上弹出牌型名（如「同花顺」），金色立体字，缩放 0.6 → 1.1 → 1.0 弹入，停留约 500ms 后上移淡出；单张不弹。
- single / pair：轻环（微调现有）。
- trio：三环（沿用）。
- straight：流线扫光加密（现有 5 条 → 7 条，加首尾辉光）。
- flush：粒子按该手牌实际花色着色——♠ 银白、♥ 朱红、♣ 翠绿、♦ 鎏金。
- fullhouse：紫金双环 + 粒子（沿用微调）。
- **four（炸弹感）**：现有双环+闪白基础上，加全屏震动（画布 translate 随机 ±6px、300ms 衰减）+ 一道粗冲击波环。
- **straightflush**：现有彩虹六环基础上，加一道从左到右的满屏流光扫过。

### 7.4 ♠3 / ♠A 身份特效（全新）

- **触发**：`app.js fxPlayed` 检测本手出牌中是否含 ♠3 或 ♠A（`s===3 && (r===3 || r===14)`），是则写 `S.fx.identityT0` 并记录座位与牌；若此后该玩家 `revealedCards` 同时含 3 与 14（独食现身），写 `S.fx.loneRevealT0`。联机模式通过对比前后 state 中该座位身份标记的本地变化触发，不走单机路径。
- **单张身份牌**（约 900ms）：
  1. 牌落桌瞬间，落点升起一道黑金竖直光柱（200ms）；
  2. 12 枚黑桃花形粒子（Canvas 路径画 ♠）从落点炸开，黑金配色；
  3. 一枚圆形黑金身份徽标（♠3 / ♠A）从桌中央沿二次贝塞尔曲线飞入该玩家座位（约 450ms），落座后并入座位旁常驻身份标记（沿用现有 revealedCards 展示，样式随新主题重画、略放大）。
- **独食现身**（约 1600ms）：
  1. 桌面压暗至 40%；
  2. ♠3、♠A 两张牌面在屏幕中央从两侧飞入合并、放大至 1.6 倍；
  3. 「独食」朱红大字从 2.2 倍砸到 1.0 倍 + 全屏震屏 + 黑红粒子爆发；
  4. 收尾后该玩家座位牌边框转朱红并常驻（替代现有小红 chip，文字「独食」保留在座位牌右上角）。

### 7.5 音效（audio.js，程序合成）

- 身份牌：一声低沉钟鸣（低频正弦+泛音衰减）；
- 独食现身：鼓点两下 + 锣声（噪声高通+指数衰减）；
- four 震屏：低频轰声。均走现有 SFX 开关。

### 7.6 app.js 联动清单

- `fxPlayed` 增加身份牌/独食检测与新时间戳；
- 脏检查（`markDirty` 条件）纳入 `identityT0`（<1000ms）与 `loneRevealT0`（<1700ms）；
- `?demo=` 调试参数扩展：`demo=identity`、`demo=lone`，便于截图验证。

## 8. 留给实现者的判断

- 具体像素值（座位牌坐标、手牌步进等）可按 750 宽实际效果微调，横屏分支按相同比例映射；
- 粒子数量在保持观感前提下以 60fps 为准下调；
- 横幅字体在 Canvas 内用现有 `txt()` 加粗模拟，不引外部字体。
