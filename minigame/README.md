# 广西十三张 · 独食 — 微信小游戏工程

这是「十三张独食（横县找朋友）」的可玩原型，已改造成微信小游戏形态：纯 Canvas 渲染，没有 DOM 依赖，**横屏**布局（`game.json` 里 `deviceOrientation: landscape`）。

## 怎么跑起来

1. 打开「微信开发者工具」→ 新建/导入项目 → 目录选本文件夹 `minigame`
2. 项目类型必须选 **小游戏**（不是小程序）
3. AppID 填自己的小游戏 AppID；`project.config.json` 里现在是占位值 `touristappid`，正式预览/真机必须替换
4. 编译即可玩；手机横屏（开发者工具里切「横屏」看效果）

不想装工具的话，同目录的 `preview.html` 双击就能在浏览器里玩（同一套代码，只是换了平台适配层；窗口横过来就是横屏布局，竖着也还能看）。

## 动效与音效

- 发牌：52 张从中央牌堆按逆时针一人一张飞向座位，约 2.1 秒，点击任意处可跳过
- 出牌：牌从座位飞向桌面（约 0.17 秒），落桌后再轻微放大回弹；同时出牌那家的座位泛起一圈金色脉冲
- 结算面板淡入上移；最新一手出牌始终金框，旧牌压暗
- 音效全为程序合成（无 mp3 文件）：发牌 tick、落桌拍击、过牌轻扫、选牌轻点、轮到你提示音、结算胜/负短旋律
- 页头「音效/静音」可随时开关；iOS 需首次触摸后才出声（已做自动解锁）

## 已实现的规则口径

- 4 人一桌，♠3 与 ♠A 持有者组队；同一人两张都在手 = 独食 1 打 3
- 首局 ♦4 起手，第一手必须含 ♦4
- 点数 3 最大、4 最小（3 > 2 > A > K > Q > J > 10 … > 5 > 4），花色 ♠ > ♥ > ♣ > ♦，对子比「一对里较大那张」
- 出牌**逆时针**：你 → 东 → 北 → 西
- 身份不公告：打出一张 ♠3/♠A 就在该家座位旁标一个；两张都被同一人打出才出现红色「独食」标
- 本轮所有出牌平铺亮出，最新一手金框，旧牌压暗
- 名次制计分：2v2 一二名 ±2、一三名 ±1、一四名 0；独食 +6/+3/−3/−6
- 进贡（第 2 局起）：按上局胜方名次发档（1&2 → 4/2 张、1&3 → 2/1 张、1&4 → 不抽），胜方各从败方任选一人抽，抽到的牌公示；抽到 ♠3/♠A 亮出→归还→重抽；还贡等量、自选、不公示；双方恒 13 张；被抽最大牌的原主人先出
- 每步 20 秒，超时按"跳过"处理：桌上有牌就自动过牌；只有轮到你起手（桌面无牌、必须出牌）时才替出最小合法牌
- 页头四个 chip 可循环切换：场次 8/12/16/24/32、重贡/轻贡、对手 新手/普通/高手、重开（连点两次确认）

## 联机（自建 WebSocket 服务端）

服务端在 `E:\AAproject\guangxi_13\server\`，无第三方依赖，回合校验、进贡、计分全在服务端，客户端只负责画和点。

1. 起服务：`node server/index.js`（默认 `ws://0.0.0.0:8787`，`PORT` 环境变量可改）
2. 客户端连法：浏览器预览默认连 `ws://当前host:8787`，可加 `?server=ws://192.168.1.5:8787`；微信侧用 `wx.setStorageSync('gx13_server','ws://…')` 指定地址
3. 进房：点页头标题下方的「单机 · 三家 AI」切到联机 → 创建房间（拿到 4 位房号）或输入房号加入；也可以直接开 `preview.html?room=1000&server=ws://127.0.0.1:8787` 自动进房
4. 房主准备齐全点「开始（空位补机器人）」；不足 4 人由机器人补位，人齐了就 4 个真人
5. 微信开发者工具里联机需勾「不校验合法域名」；真机必须把 `ws://` 换成已备案的 `wss://` 域名，否则连不上

协议（JSON，客户端 → 服务端）：`create / join / ready / start / play / pass / draw / return / next / ping`；服务端回 `hello / joined / state / err / pong`，`state` 是按你的座位旋转过的完整视图（只带你自己的手牌）。

进贡超时也自动处理：该抽不抽的，20 秒后服务端代抽并代还，不会卡局。
